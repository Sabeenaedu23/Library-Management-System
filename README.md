# 📚 Library Management System

## 📌 Project Overview
The Library Management System is a web-based application developed to simplify and manage library operations. It allows users to maintain book records, search for books, and manage book issuing and returning efficiently.

## 🚀 Features
- Add and manage book records
- Search for books easily
- Issue books
- Return books
- Store and manage data using SQLite
- Simple and user-friendly interface

## 🛠️ Technologies Used
- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript

## 📂 Project Purpose
This project was developed to strengthen my practical knowledge of Python, Flask, database management, and full-stack web development.

## ⚙️ How to Run the Project

1. Clone this repository:
   ```bash
  https://sabeenaedu23.github.io/Library-Management-System/
   ```
2. Navigate to the project folder:
   ```bash
   cd library-management-system
   ```
3. Install Flask:
   ```bash
   pip install flask
   ```
4. Run the application:
   ```bash
   python app.py
   ```
5. Open your browser and visit:
   ```text
   http://127.0.0.1:5000/
   ```
